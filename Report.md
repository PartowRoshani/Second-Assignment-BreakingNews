# Project Title

News Aggregator

Overview:
A simple Java-based program that fetches the latest news articles from NewsAPI, displays the titles, and allows users to choose and read detailed news articles.

## Description

This project is designed to allow users to retrieve, view, and read news articles from various sources. Using the NewsAPI, the program fetches articles based on a keyword (such as "Tesla") and presents the titles to the user. The user can then choose which article to read and view detailed information about it. It’s a simple terminal-based app aimed at providing a basic news aggregation service.

## Getting Started

### Dependencies

Dependencies
Operating System: Windows 10 (or any platform supporting Java 11+)
Java: JDK 11 or above

Libraries:
com.google.gson for parsing JSON
HttpClient for sending HTTP requests (available in Java 11 and above)

Gradle: 13.2

### Installing

1) Clone this repository to your local machine
2) Import the project into your IDE(e.g.,InelliJ IDEA , Eclipse)


### Executing program

1)After installation and importing the project into your IDE, run the program from within your IDE or execute it from the command line using:


```
java -jar NewsAggregator.jar
```
2) Upon running the program, you’ll be able to select a news article from the list and read more about it.



## Help

If you encounter any issues, ensure that your API key is correctly entered and that your internet connection is active.
For more information, refer to the NewsAPI documentation.
